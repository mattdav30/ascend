# Ascend

A real life RPG fitness app. Train, run and eat well to level up a 3D hero, awaken glyphs and climb seven ranks.

## Features

- 3D anime style hero (three.js) with custom hair, eyes, skin and outfit. Class gear and rank armour grow as you level.
- Four classes: Berserker, Ranger, Monk and Paladin, each with its own XP bonus and weapon.
- Profile with height, weight, age and goal, used to set daily calorie and protein targets.
- Quests: a 10 chapter main storyline, daily and weekly quests that track your logs, plus your own repeating workouts.
- Run tracking with live GPS, GPX import from Strava or Garmin, and a demo run. Routes draw with km markers.
- Fuel tracking with custom meals, macros and one tap favourites.
- Glyph codex: earn shards, awaken 12 glyphs and inscribe them for bonuses. Glyph rain runs behind the app and a full ascension sequence plays on every level up.
- 20 achievements and an in app notification centre with reminders.

## Run it

Open `index.html` in a browser. Progress saves in the browser's local storage.

Live GPS needs the page served over HTTPS, for example through GitHub Pages: Settings, Pages, deploy from the `main` branch.
